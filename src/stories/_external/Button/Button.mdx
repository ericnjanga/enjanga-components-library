## Unit tests

### Exports a primary native button with a safe default type

Verifies the public package export, default variant, and non-submitting native button type.

### Renders each variant

Checks that primary, secondary, and tertiary select their respective styles.

### Keeps each icon decorative

Checks both icons remain hidden from assistive technology and enable icon spacing without changing the accessible name.

### Omits unused icons

Checks that text-only buttons contain no icon element or icon spacing class.

### Supports pointer and keyboard activation

Verifies tab focus and one click callback for each pointer, Enter, and Space activation.

### Prevents disabled activation

Verifies a disabled button cannot invoke its handler and is skipped during keyboard navigation.

### Submits only when configured

Verifies the default does not submit a surrounding form while an explicit submit button does.

### Forwards native props and refs

Verifies consumers can access the DOM button and supply classes, accessible labels, pressed state, and form attributes.
