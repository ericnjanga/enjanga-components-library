  <h2 id="purpose-what-is-it" style={{ position: 'relative' }}>Purpose / What it is?</h2>
  <p>The <strong>PictogramTile</strong> component is a flexible, reusable content block that displays a <strong>title, media (image/pictogram), and optional interactivity</strong>. It can act as:</p>
  <ul>
  <li>
  <p>A <strong>navigational card</strong> (linking internally or externally).</p>
  </li>
  <li>
  <p>An <strong>interactive tile</strong> that opens a modal for detailed content.</p>
  </li>
  <li>
  <p>A <strong>visual tile</strong> for highlighting featured information.</p>
  </li>
  </ul>



  <Primary />
</div>


<div style={{ position: 'relative', paddingTop: '50px', marginTop: '-50px', zIndex: '1', marginBottom: '60px' }}>
  <h2 id="when-to-use" style={{ position: 'relative' }}>✅ When to Use</h2>
  <p>Use <strong>PictogramTile</strong> when you need to:</p>
  <ul>
  <li>
  <p>Present <strong>clickable content previews</strong>, like blog posts, resources, or case studies.</p>
  </li>
  <li>
  <p>Highlight <strong>features or services</strong> with an icon, image, or pictogram.</p>
  </li>
  <li>
  <p>Provide <strong>expandable details</strong> inside a modal without leaving the current page.</p>
  </li>
  <li>
  <p>Create <strong>consistent card-like layouts</strong> across different sections.</p>
  </li>
  </ul>
</div>



<div style={{ position: 'relative', paddingTop: '50px', marginTop: '-50px', zIndex: '1', marginBottom: '60px' }}>
  <h2 id="when-not-to-use" style={{ position: 'relative' }}>❌ When not to use</h2>
  <p>Avoid using <strong>PictogramTile</strong> when:</p>
  <ul>
  <li>
  <p>You just need a <strong>simple button</strong> (use <code>Button</code> instead).</p>
  </li>
  <li>
  <p>The content belongs in a <strong>list/table</strong> rather than a card-based layout.</p>
  </li>
  <li>
  <p>You don't need <strong>interactivity, links, or modal support</strong> — a plain <code>Tile</code> or <code>Banner</code> may be a better fit.</p>
  </li>
  <li>
  <p>You want <strong>form inputs or user actions</strong> inside; this component is for display and navigation only.</p>
  </li>
  </ul>
</div>


<div style={{ position: 'relative', paddingTop: '50px', marginTop: '-50px', zIndex: '1', marginBottom: '60px' }}>
  <h2 id="property-validation" style={{ position: 'relative' }}>Property validation</h2>

  <div>
    <div>
    <strong>Rule 1: Tile mode (Link vs. Modal)</strong>
    </div>

    <div>
    A <code>PictogramTile</code> must be either:
    </div>
  </div>

  <ul>
    <li><strong>Link mode</strong>: Set <code>linksTo</code> to a valid URL or route</li>
    <li><strong>Modal mode</strong>: Set <code>modalIsAvailable</code> to <code>true</code></li>
    <li><strong>Static mode</strong>: Neither links nor modal (for display only)</li>
  </ul>

  <div>
    🚫 <strong>Never both at the same time</strong> — a <code>PictogramTile</code> cannot act as a link and modal trigger simultaneously.
  </div>

  <div style={{ marginTop: '20px' }}>
    <div>
    <strong>Rule 2: Media validation</strong>
    </div>

    <div>
    When using media, you must specify exactly one type:
    </div>
  </div>

  <ul>
    <li><code>media: 'pictogram'</code> + <code>mediaPictogram</code> (required)</li>
    <li><code>media: 'image'</code> + <code>mediaImage</code> (required)</li>
    <li>No media (optional)</li>
  </ul>

  <div>
    🚫 <strong>Never multiple media types</strong> — choose one or none.
  </div>
</div>
